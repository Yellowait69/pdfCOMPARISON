# ProfileSettingsWindow

La fenêtre `ProfileSettingsWindow` offre une interface graphique complète en 3 onglets permettant à l'utilisateur final de personnaliser le moteur de comparaison sans modifier le code :

1. **Zones d'Exclusion Géométriques (X/Y & Dessin Souris)** : Tableau éditable + Canevas A4 interactif permettant de charger un PDF témoin et de dessiner des zones d'exclusion au curseur (*Rubber-band Lasso*).
2. **Masquage Dynamique par Regex** : Gestion des règles d'expressions régulières (dates, numéros de facture, références, noms de clients) avec testeur en direct.
3. **Tolérances Anti-Faux-Positifs, Filigranes & Appairage** : Réglage fin des seuils de décalage de lignes (*word-wrap reflow*), des tailles de police des filigranes et des expressions régulières d'appairage de fichiers.
